# Storyboard: Form Block Overview

The Storyboard is the sidebar component of the Workbench that provides a scrollable overview of all the blocks in your form. It helps you navigate through your form blocks quickly and efficiently.

## What is the Storyboard?

The Storyboard is essentially a compact representation of your form structure that:

-   Shows all blocks in your form in sequential order
-   Allows quick navigation between blocks
-   Provides a way to reorder blocks through drag and drop
-   Displays visual indicators for blocks with conditional logic

## Using the Storyboard

### Navigating Your Form

The Storyboard makes it easy to move through your form:

1. **Scrolling**: Scroll up and down to see all the blocks in your form
2. **Block Selection**: Click on any block to select it and display its properties in the main Workbench area
3. **Visual Overview**: Quickly see your entire form structure without having to navigate through the form itself

### Managing Blocks

The Storyboard provides essential block management capabilities:

1. **Reordering**: Drag and drop blocks to change their order in the form
2. **Adding Blocks**: Use the "+" button at the bottom of blocks to add new blocks
3. **Removing Blocks**: Select a block and use the delete option to remove it
4. **Block Status**: See visual indicators for required fields or blocks with conditional logic

### Logic Indicators

When you've added conditional logic to blocks, the Storyboard helps you keep track:

-   Blocks with conditional logic have visual indicators
-   You can quickly identify which blocks have special behavior

### Form Organization

For forms with multiple questions, the Storyboard helps you:

-   Keep track of the overall structure
-   Ensure a logical question sequence
-   Easily navigate to specific sections
