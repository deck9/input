# Checkboxes 

Checkboxes allow users to select multiple options from a list.

## How to use:

1. Select **Checkboxes** as the input type.
2. Enter the question or prompt.
3. Add your options, one per line.
4. Optionally, set default selections.

::: tip Best Practice
 💡 Use when you want users to be able to select more than one option. 
:::
