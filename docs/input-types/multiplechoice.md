# Multiple Choice 🔘

This input type allows users to select one option from a list of choices, perfect for questions with mutually exclusive answers.

## How to use:

1. Choose **Multiple Choice (Radio)** as the input type
2. Enter the question or prompt
3. Add your answer options, one per line
4. Toggle the "Required" option if necessary

## Features:

-   **Single Selection**: Users can select exactly one option
-   **Visual Clarity**: Clear indication of which option is selected
-   **Option Ordering**: Arrange options in a meaningful sequence
-   **Randomization**: Option to randomize choice order to reduce bias (if available)

## Example Uses:

-   **Preferences**: "Which is your favorite option?"
-   **Yes/No Questions**: "Are you interested in our newsletter?"
-   **Categorization**: "Which category best describes you?"
-   **Selection**: "Choose the product you're most interested in"
-   **Opinions**: "How would you rate our service?"

::: tip Best Practice
🌟 Keep options mutually exclusive and limit the number of choices to prevent overwhelming users. Consider adding an "Other" option for unexpected responses, and arrange options in a logical order (alphabetical, numerical, or by relevance).
:::

## When to use Multiple Choice:

-   When users should select only one option from a list
-   For questions with mutually exclusive answers
-   When you need clear, categorizable responses
-   For questions where options are predefined and comprehensive
-   When analyzing response distribution is important

::: warning Note
If users might need to select more than one option, use the **Checkboxes** input type instead.
:::
