# Long Text 📄

The Long Text input type provides a multi-line text area for collecting detailed, open-ended responses from users. It's ideal for comments, feedback, descriptions, and any situation where users need to enter more than a brief phrase.

## How to use:

1. Select **Long Text** as the input type
2. Enter the question or prompt
3. Configure the text area options:
   - **Rows**: Number of visible text rows (1-10, default: 5)
   - **Maximum Characters**: Limit on response length (default: 500)
   - **Placeholder**: Hint text shown when the field is empty
4. Toggle the "Required" option if necessary

## Features:

- **Multi-line Input**: Allows line breaks and paragraph formatting
- **Character Counter**: Real-time display of characters used
- **Character Limit**: Optional maximum character constraint
- **Adjustable Height**: Customize visible rows to fit your form design
- **Visual Feedback**: Counter changes color when approaching the limit
- **Scrollable Area**: Users can enter content beyond the visible area
- **Mobile Friendly**: Properly displays on all device sizes

## Example Uses:

- **Comments**: "Please share any additional comments or feedback"
- **Explanations**: "Please explain your reasoning in detail"
- **Descriptions**: "Describe the issue you're experiencing"
- **Open Feedback**: "What improvements would you suggest?"
- **Detailed Information**: "Tell us about your experience with our product"
- **User Stories**: "Share your story of how our service helped you"

::: tip Best Practice
💡 Set an appropriate character limit based on the expected response length. For short paragraphs, 500 characters is usually sufficient, while detailed feedback might require 1000+ characters. Add clear instructions about the level of detail you're looking for to guide users.
:::

## When to use Long Text:

- When you need more than a single line of text
- For qualitative, open-ended responses
- When detailed explanations are required
- For collecting user stories or testimonials
- When multiple paragraphs might be necessary
- For feedback that requires elaboration

::: warning Note
While Long Text fields are great for detailed responses, very long responses may be difficult for users to type, especially on mobile devices. For extremely detailed information, consider breaking your questions into smaller, more focused parts.
:::

## Technical Details:

- Text can include line breaks and paragraphs
- The character counter updates in real-time as users type
- Maximum storage capacity is virtually unlimited
- Long Text fields cannot include rich formatting (bold, italics, etc.)
