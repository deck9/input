# Number 🔢
This input type is used for numerical responses.
 
## How to use:

1. Choose **Number** as the input type.
2. Enter the question or prompt.
3. Optionally, set minimum and maximum values.
4. Specify step size if needed (e.g., increments of 0.5).

::: tip Best Practice
 🌟 Use for ages, quantities, or any numeric data. Specify units if applicable.
:::
