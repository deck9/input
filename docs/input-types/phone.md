# Phone Number ☎️

This input type is specifically designed for collecting phone numbers with appropriate formatting and validation.

## How to use:

1. Select **Phone Number** as the input type
2. Enter the prompt asking for the phone number
3. Optionally, add a placeholder showing the expected format
4. Configure validation requirements if needed

## Features:

- **Format Guidance**: Helps users understand the expected phone number format
- **Specialized Keyboard**: Mobile devices display the number keypad for easier entry
- **Input Validation**: Basic checks to ensure input follows a phone number pattern
- **International Support**: Can accept various phone number formats

## Example Uses:

- **Contact Information**: Collecting contact details for follow-up
- **Account Registration**: Adding phone number to user profiles
- **Support Requests**: Getting callback numbers for customer service
- **Delivery Information**: Contact numbers for delivery services
- **Appointment Scheduling**: Phone numbers for confirmation calls

::: tip Best Practice
🌟 Always specify what the phone number will be used for and include a privacy statement. For international forms, include example formatting or country code instructions.
:::

## When to use Phone Number input:

- When you need to contact users by phone or SMS
- For authentication or verification purposes
- When phone is a required contact method
- For emergency contact information
- When you need a reliable way to reach users outside of email

::: warning Privacy Note
Phone numbers are considered personally identifiable information (PII). Ensure you have appropriate consent and data protection measures in place when collecting phone numbers.
:::
