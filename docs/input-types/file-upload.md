# File Upload 📁

The File Upload input type allows users to attach files to their form responses. It supports multiple file types and offers a user-friendly drag-and-drop interface.

## How to use:

1. Choose **File Upload** as the input type
2. Enter instructions for what files users should upload
3. Configure the upload settings:
    - **Maximum Files**: Set how many files users can upload
    - **Maximum File Size**: Limit file size (in MB)
    - **Allowed File Types**: Choose which file formats are accepted

::: tip Best Practice
< Be specific about what files you're looking for and any requirements (format, size, resolution, etc.) to avoid confusion and unsuccessful uploads.
:::

## Features:

-   **Drag-and-Drop**: Users can drop files directly into the upload area
-   **Multiple File Support**: Accept one or more files per upload field
-   **File Type Filtering**: Restrict uploads to specific file types
-   **Size Limits**: Control maximum file sizes to prevent excessively large uploads
-   **Mobile Friendly**: Optimized interface for mobile devices
-   **Upload Progress**: Visual indicators show upload progress for larger files

## File Type Options:

-   **Images**: Accept photos and graphics (jpg, png, gif, etc.)
-   **Documents**: Accept text and document files (pdf, doc, txt, etc.)
-   **Audio**: Accept sound files (mp3, wav, etc.)
-   **Video**: Accept video files (mp4, mov, etc.)
-   **Custom**: Specify exactly which file extensions are allowed

## Example Uses:

-   **Job Applications**: Resume and portfolio uploads
-   **Support Requests**: Screenshots or documentation of issues
-   **Photo Submission**: Contest entries or profile pictures
-   **Document Collection**: ID verification or signed forms
-   **Media Sharing**: Audio or video uploads for feedback

## When to use File Upload:

-   When you need users to submit existing files rather than typing information
-   For collecting visual or media information that can't be entered as text
-   When documentation or evidence needs to be attached to a submission
-   For any form that requires document collection as part of the process

::: warning Storage Considerations
Files take up storage space in your system. Consider implementing automatic file expiration or cleanup processes if you collect large numbers of files.
:::
