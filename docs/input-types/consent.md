# Consent ✓

The Consent input type is designed specifically for gathering agreement from users for terms, conditions, privacy policies, or other consent-based information.

## How to use:

1. Choose **Consent** as the input type
2. Enter a clear message explaining what the user is consenting to
3. Configure the consent option with a concise label
4. Toggle "Opt-In Required" if the consent is mandatory to proceed

::: tip Best Practice
< Keep consent messages clear and specific. Explain exactly what users are agreeing to, and include links to relevant policies when appropriate.
:::

## Features:

-   **Dedicated Consent Format**: Optimized for obtaining user permissions and agreements
-   **Required Toggle**: Make consent mandatory when needed for compliance reasons
-   **Clear Presentation**: Shows as a checkbox with explanatory text
-   **Legal Compliance**: Helps meet GDPR, CCPA, and other privacy regulation requirements

## Example Uses:

-   **Privacy Policy Acceptance**: Getting consent to collect and process personal data
-   **Terms of Service**: Confirming users have read and accepted your terms
-   **Marketing Opt-ins**: Getting permission to send marketing communications
-   **Cookie Consent**: Getting agreement for using cookies (beyond essential ones)
-   **Data Processing**: Obtaining explicit permission to use submitted data

## When to use Consent inputs:

-   For any legal agreement that requires explicit user approval
-   When collecting personal information that requires permission under privacy laws
-   For opt-in marketing communications
-   Whenever you need documented proof that a user has agreed to specific terms

::: warning Legal Note
Different jurisdictions have different requirements for valid consent. For legal compliance, consult with a legal professional to ensure your consent mechanisms meet relevant requirements in your regions of operation.
:::
