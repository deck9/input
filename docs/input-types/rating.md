# Rating ⭐

The Rating input type allows users to provide feedback on a visual scale using icons like stars, hearts, or other symbols. It's perfect for collecting opinion-based or satisfaction data in an engaging way.

## How to use:

1. Choose **Rating** as the input type
2. Enter the prompt for what's being rated
3. Configure the rating options:
   - **Min Rating**: Starting point for the scale (default: 1)
   - **Max Rating**: Maximum value on the scale (default: 5)
   - **Left Label**: Optional text at the start of the scale (e.g., "Poor")
   - **Right Label**: Optional text at the end of the scale (e.g., "Excellent")
   - **Icon**: Choose from stars, hearts, trophies, and other symbols
   - **Color**: Customize the color of the rating icons
4. Toggle the "Required" option if necessary

## Features:

- **Visual Appeal**: Engaging, interactive rating experience with customizable icons
- **Flexible Range**: Set any numerical range for your rating scale
- **Icon Options**: Choose from multiple icon types:
  - Stars (default)
  - Hearts
  - Trophies
  - Crowns
  - And more...
- **Custom Color**: Match the rating color to your form's design
- **Scale Labels**: Add descriptive labels at each end of the scale
- **Hover Preview**: Users see a preview of their selection on hover
- **Clear Option**: Double-click to clear selection (if not required)
- **Keyboard Support**: Use number keys to select rating values

## Example Uses:

- **Customer Satisfaction**: "How would you rate your experience?"
- **Product Reviews**: "How many stars would you give this product?"
- **Feedback Forms**: "Rate the usefulness of this information"
- **Event Evaluations**: "How would you rate this event?"
- **Service Quality**: "Rate our customer service"
- **Content Ratings**: "How helpful was this article?"

::: tip Best Practice 
🌟 Be clear about what the rating scale represents. Is 5 excellent or average? Adding descriptive labels at each end of the scale helps users understand the meaning. Follow rating questions with an optional comment field to collect qualitative feedback about the rating given.
:::

## When to use Rating:

- When you want to collect opinion or satisfaction data
- For feedback that works well on a numerical scale
- When a visual, engaging input method would increase response rates
- For questions where a sliding scale of opinions is appropriate
- When you want quick, easy-to-analyze quantitative feedback

::: warning Note
Rating differs from Scale input in its visual presentation. Use Rating when you want iconic, visual feedback (stars, hearts), and use Scale when you want a more traditional numbered scale appearance.
:::
