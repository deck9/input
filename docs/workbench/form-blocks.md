# Form Blocks: Building Your Form

Form blocks are the fundamental building components of any form in Input. Each block represents a distinct element in your form, such as a question, information display, or user interaction point. Understanding how to work with blocks is essential for creating effective forms.

## Block Types

Input offers a variety of block types to gather different kinds of information:

### Content Blocks

-   [**Text only**](/input-types/no-interaction): Displays text without requiring user input, useful for instructions or explanations

### Text Input Blocks

-   [**Short text**](/input-types/short-text): For collecting brief responses like names or titles
-   [**Long text**](/input-types/long-text): For gathering detailed responses, comments, or feedback
-   [**Email**](/input-types/email): Specifically for email addresses, with built-in validation
-   [**Phone**](/input-types/phone): For phone numbers, with optional formatting
-   [**Link**](/input-types/link): For collecting website URLs
-   [**Hidden text**](/input-types/secret): For sensitive information like passwords, with masked input

### Choice Blocks

-   [**Single choice**](/input-types/multiplechoice): Allows selection of one option from several choices
-   [**Checkboxes**](/input-types/checkboxes): Allows selection of multiple options from a list
-   [**Scale**](/input-types/scale): Presents a numerical scale (e.g., 1-10) for rating questions
-   [**Rating**](/input-types/rating): Star-based rating system for satisfaction or quality assessment

### Specialized Blocks

-   [**Number**](/input-types/number): For numerical input with optional min/max validation
-   [**Date**](/input-types/date): For collecting calendar dates
-   [**File upload**](/input-types/file-upload): Allows users to upload files or images
-   [**Consent**](/input-types/consent): For collecting explicit consent with terms or policies

## Adding Blocks to Your Form

To add a new block to your form:

1. Click **Add question** at the end of the form, point between two questions and click **Add question here**, or choose **Add question below** in a question's menu (…)
2. Choose the type in the picker, or type to search for it
3. The new question opens right there, with the cursor in its text

To change the type of an empty question, type "/" in its text.

## Block Groups

Organize related blocks together:

1. **Creating a Group**: Click **Add group** at the end of the form and give it a name
2. **Filling a Group**: Use **Add question to this group** in the group's menu, or drag questions into it
3. **Hiding a Group**: **Hide group** in its menu hides all its questions at once, and a rule on the group shows or hides them together
