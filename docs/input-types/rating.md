# Rating ⭐

Use this input type to collect ratings on a predefined scale.

## How to use:

1. Choose "Rating" as the input type.
2. Enter the prompt for what's being rated.
3. Set the scale (e.g., 1-5 stars, 1-10 points).

::: tip Best Practice 
💡 Consider using visual elements like stars or emojis to make the rating more engaging. Also, adding a follow-up question can help gather more detailed feedback about the rating given.
:::
