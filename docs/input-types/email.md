# Email 📧

This input type is specifically designed for collecting email addresses with appropriate formatting and validation.

## How to use:

1. Select **Email** as the input type
2. Enter the prompt asking for the email address
3. Optionally, add a placeholder example (e.g., "name@example.com")
4. Toggle the "Required" option if necessary

## Features:

- **Format Validation**: Ensures input follows a valid email format
- **Specialized Keyboard**: Mobile devices display a keyboard optimized for email entry
- **Autocomplete Support**: Works with browser autocomplete for easier form filling
- **Data Typing**: Properly categorizes the data as an email for processing

## Example Uses:

- **Account Creation**: Registering users with a unique identifier
- **Newsletter Signup**: Collecting addresses for marketing communications
- **Contact Information**: For follow-up communications
- **Login Credentials**: As username for authentication
- **Receipt Delivery**: For sending digital receipts or confirmations

::: tip Best Practice
🌟 Always include a clear privacy statement when collecting email addresses. Explain exactly how the email will be used and whether users will receive communications. Consider double opt-in for marketing lists.
:::

## When to use Email input:

- When you need to contact users electronically
- For account creation and management
- When sending automated responses or confirmations
- For newsletter or marketing subscriptions (with proper consent)
- When email is a required identification method

::: warning Privacy Note
Email addresses are considered personally identifiable information (PII). Ensure you have appropriate consent and data protection measures in place when collecting and storing email addresses.
:::
