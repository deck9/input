# Multiple Choice (Radio) 🔘

This input type allows users to select one option from a list of choices.

## How to use:

1. Choose **Multiple Choice (Radio)** as the input type.
2. Enter the question or prompt.
3. Add your answer options, one per line.
4. Optionally, set a default selection.

::: tip Best Practice
🌟 Keep options mutually exclusive and limit the number of choices to prevent overwhelming users.
:::
