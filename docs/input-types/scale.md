# Scale 📊
This input type allows users to select a value within a specified range.

## How to use:

1. Select "Scale" as the input type.
2. Enter the question or prompt.
3. Set the minimum and maximum values for the scale.
4. Optionally, add labels for the scale endpoints.   

::: tip Best Practice 
🌟 Provide clear context for what the scale represents (e.g., 1 = Strongly Disagree, 10 = Strongly Agree).
:::
