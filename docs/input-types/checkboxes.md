# Checkboxes ✅

Checkboxes allow users to select multiple options from a list, making them perfect for questions where more than one answer might apply.

## How to use:

1. Select **Checkboxes** as the input type
2. Enter the question or prompt
3. Add your options, one per line
4. Toggle the "Required" option if necessary

## Features:

-   **Multiple Selection**: Users can choose any number of options (0 to all)
-   **Option Ordering**: Arrange options in a meaningful order or hierarchy
-   **Data Analysis**: Easily analyze which options are most frequently selected

## Example Uses:

-   **Preferences**: "Which features are you interested in?"
-   **Demographics**: "Which age groups do you work with?"
-   **Selections**: "Select all services you currently use"
-   **Availability**: "Which days of the week work for you?"
-   **Categories**: "Which topics would you like to learn more about?"

::: tip Best Practice
🌟 Keep your option list focused and organized. Consider alphabetical ordering for unbiased responses, or logical grouping for related options. When possible, include an "Other" option with a text field for unexpected responses.
:::

## When to use Checkboxes:

-   When users might need to select multiple items from a list
-   For "Select all that apply" questions
-   When you need to collect multiple categorical data points
-   For preference selection where multiple choices are valid
-   When you want to offer comprehensive option coverage

::: warning Note
If you want users to select only one option from a list, use the **Multiple Choice (Radio)** input type instead.
:::
